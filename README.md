# Курсовая работа 3
# Описание:
В работе выполнен трекер самолетов. Через главную функцию программы пользователь получает информацию о воздушных судах
находящихся над определенной территорией. Программа выполняет запрос в результате которого производится запись бортов в 
базу данных.

# Установка:
1. Клонируйте репозиторий ''' git clone '''.
2. Установите зависимости: ''' pip install -r requirements.txt '''
3. Запуск из модуля main.py


# Тестирование:
Выполнено частичное тестирование модулем pytest, на боллее чем 75% из условия курсовой работы, так же выполнено 
логирование всех функций проекта с возможностью отслеживания в лог файлах работы функций их переменных и дата фреймов 
используемых и образуемых во время работы функций.
