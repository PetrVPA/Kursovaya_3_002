# Описание:
В работе выполнен трекер самолетов. Через главную функцию программы пользователь получает информацию о воздушных судах
находящихся над определенной территорией. Программа выполняет запрос в результате которого производится запись бортов в 
базу данных. Реализована процедура отобрадения воздушных судов "государство"-"количество бортов". Процедура отображения
всех воздушныз судов вошедших в базу данных. Процедура опреднления средней скорости всех воздушных судов в базе данных.
Процедура определения воздушных судов скорость которых больше средней скорости. Процедура позволяющая определить в каких
позывных присутствуют символы введенные пользователем. В функции main.py реализована демонстрация с минимальным участием
пользователя, за которым остается решения о продолжении работы программы и финальное введение символов входящих в
позывной воздушного судна. 

# Установка:
